Read this first

This connector is more work to set up than the others, and it is fair to know why before you start.

  • X has no free API, so Mawkingbird reads through a third-party service that resells public X data. You bring your own key and pay them per request.
  • Those services refuse web browsers, so every request also has to go through a CORS proxy. You will see this happen when you press Test.
  • It is read-only. You can read posts and follow accounts locally. You cannot like, repost or reply — those need a real X login, which this app never asks for.

"Follow" here means a subscription stored in this browser. It is not a follow on X, and nobody on X is notified.
