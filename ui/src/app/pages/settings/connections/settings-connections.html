🔑 How long to keep credentials

GitHub, Raindrop.io and Bluesky are connected by pasting a long-lived secret. There is no server here to hold those, so they sit in this browser until something removes them. Pick how long that should be — when a connection reaches its limit it is disconnected and the credential is deleted from this browser. Reconnecting takes a few seconds and restarts the clock.

This does not apply to Dropbox, which uses a proper OAuth flow with short-lived tokens that expire on their own.
