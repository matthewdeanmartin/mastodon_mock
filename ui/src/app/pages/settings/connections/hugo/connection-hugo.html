✍️ Blog (Hugo)

Publish Markdown posts to your own Hugo site on GitHub. A post is a file: Mawkingbird commits it to your repository, and GitHub builds the site. Nobody else hosts your writing, and there is no blog service that can close your account.

{{ scopeDetail }}

  1. Have a Hugo site in a GitHub repository. Starting from scratch? Hugo's quick start ↗ — or fork any Hugo theme's example site, then turn on GitHub Pages for it.
  2. Create a fine-grained personal access token ↗. Under Repository access pick Only select repositories and choose your blog repo. Under Permissions → Repository set Contents to Read and write, and Actions to Read-only (that one is for showing build status later).
  3. Paste it below with your repository details, then save. We check them before storing.

This token can commit files to the repository you scope it to. It is stored in this browser's localStorage, never sent to Mawkingbird, and sent only to api.github.com — no CORS proxy is involved, because GitHub's API accepts browser requests directly. Scope it to the one blog repository, and revoke it in GitHub to invalidate it.

Read your blog back

Your Hugo site publishes an RSS feed, so Mawkingbird can read your own posts the same way it reads any other feed — no special handling, and no CORS proxy if your site is on GitHub Pages.
