✍️ Blog (Mataroa)

Publish Markdown posts to one Mataroa blog from the composer. One Mataroa blog per signed-in account; the Blogger connector is separate and can be connected at the same time.

{{ scopeDetail }}

  1. Open Mataroa’s dashboard and copy the API key from its API page.
  2. Set up a CORS proxy that forwards custom headers.
  3. Enter the public address of your blog, then save and test the connection.

Mataroa’s API key can publish, edit, and delete your writing. Its API does not accept browser requests directly, so the configured CORS proxy will see this key and the posts you publish. Only continue with a proxy operator you trust.
