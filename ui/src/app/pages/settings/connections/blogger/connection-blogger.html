Use my own Google project

Optional. This app ships with a shared Google project, which is enough for most people. Bring your own if you hit its limits — Google caps an unverified app at 100 users, and everyone using the shared project shares its Blogger quota. Your own project also skips the unverified-app warning, since you own it.

  1. In the Google Cloud console ↗, create a project and enable the Blogger API.
  2. Create an OAuth client id of type Web application.
  3. Add this exact address to its Authorized redirect URIs: {{ callbackUrl }}
  4. Paste the client id below. The client secret is not needed — leave it in Google.
