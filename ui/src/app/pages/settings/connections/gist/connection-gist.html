📝 GitHub Gist

Publish pastes as gists on your GitHub account. Gist becomes one more option wherever you can post a paste — and because every paste service is also a draft source, anything you create shows up in Drafts and in Write alongside the rest of your unpublished writing.

  1. Open GitHub → Settings → Developer settings → Personal access tokens ↗ and generate a classic token.
  2. Tick gist, and nothing else. This connector needs no repository access at all.
  3. Paste it below and connect.

This token can create, edit, and delete gists on your account. It is deliberately separate from the token used by the GitHub connector (read-only) and the one used by Hugo (one repository) — so that no single stored string reaches more of your account than the feature it belongs to.

What a gist paste is

  • Public gists are listed on your GitHub profile. Unlisted ones are GitHub's "secret" gists — not listed anywhere, but anyone with the link can read them. Neither is private.
  • Gists never expire. There is no burn-after-reading and no time limit.
  • Editing works from here, unlike the anonymous paste services: the gist belongs to your account rather than to an edit code saved in this browser. Losing this browser does not lose the gist.
  • Only gists with a single file are listed back — a multi-file gist is a project, not a note.
