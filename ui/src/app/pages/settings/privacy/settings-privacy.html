What this app counts

Analytics
Anonymous page counts only — which kinds of page get used, never which account, post or tag you looked at, and never a query string. Turn this off and the analytics script is never loaded at all: nothing is fetched, counted or sent. The script is served from this site, not from a third party. This one is stored in your browser, so there is nothing to save and nothing to fail.
